| 【HR】 | ゲーム：ホロウ・リアリゼーション（新生アインクラッド風世界。旧SAO系モブ再登場） |
| ※要検証 | 記憶・二次資料ベースで原典未確認の項目。SAW実装前に原典照合推奨 |

**注意事項**
- 原作でモブの「レベル」が数値明示されることはほぼ無い。本資料のLvは「攻略時のキリトのLv」等から逆算した**設計用の目安**。
- ゲーム作品ごとに同名ボスでも仕様が異なる（特にSAOIFは独自解釈が多い）。
- ドロップは原作で明言されたもの以外は「素材/コル/回復結晶等」と概括。

**レベル帯設計の目安（原作準拠の逆算）**
- 1層ボス攻略時：キリトLv14前後、レイド平均Lv10前後【SAOP】
- 74層攻略時：キリトLv96【原作1巻】
- → 概算式：**適正Lv ≒ 階層数 + 10〜22（上層ほど乖離が大きい）**。SAW実装なら「階層×1.1 + 12」程度の曲線を推奨。

## 2. フィールドボス／イベントボス（階層ボス以外の名前付き敵）

### ニコラス・ザ・レネゲード 【原作2巻/アニメ3話】
- **階層/エリア**：35層「迷いの森」の大樅の木の下（クリスマスイベント限定・2023年12月24日深夜に出現）
- **外見**：巨大な邪悪サンタクロース型。袋と斧を携える
- **戦闘**：イベントボスとしては高難度。キリトがソロ討伐（戦闘描写自体は省略）
- **ドロップ**：**蘇生アイテム**（死亡後10秒以内に使用すれば復活可能。ただしSAOでは死亡＝即データ消滅のため実用条件が極めて厳しい）。キリトはクラインに譲渡
- **SAW実装メモ**：期間限定スポーン＋唯一無二ドロップの設計例として最適

### X'rphan the White Wyrm（西山の白竜） 【原作2巻/アニメ7話】
- **階層/エリア**：55層・西山（雪山）の山頂付近／巣は縦穴の底
- **Lv目安**：60台後半（55層適正よりかなり格上の準ボス）
- **攻撃**：冷気ブレス、飛行からの急襲、竜巻状の吹き上げ、尻尾薙ぎ
- **関連アイテム**：巣の中に**クリスタライト・インゴット**（竜が結晶を捕食した後の排泄物由来のレア鍛冶素材）。リズベットがこれで片手剣**《ダーク・リパルサー》**を鍛造
- **SAW実装メモ**：「討伐ドロップではなく巣の採取物」という入手経路が特徴

### ザ・ファタル・サイス 【原作2巻「朝露の少女」/アニメ11〜12話】
- **階層/エリア**：1層・黒鉄宮の地下に隠された「隠しダンジョン」最深部（圏内のはずの領域）
- **外見**：黒衣の死神型。巨大な鎌
- **戦闘仕様**：カラーカーソル無し＝レベル・HP測定不能の規格外。攻撃は最前線プレイヤーでも即死級。事実上戦闘不可能な超越個体で、ユイが管理者権限級のオブジェクト操作で消滅させた
- **SAW実装メモ**：「勝てない演出用ボス」の原型。ゲーム【IM/HF】系では通常ボスとして再解釈され「0層ボス」扱いされることもある

### マグナテリウム 【SAOP3巻】
- 4層のフィールドボス級大型火炎獣（詳細は§1の4層参照）

### フォールン・エルフ将軍・幹部級 【SAOP3〜7巻】
- エルフ戦争クエストの節目に登場する人型ネームド敵。短剣・毒・拘束系を使う暗殺者型で、「五つの秘鍵」強奪など物語進行に直結。イベント戦のため通常ドロップよりクエストフラグが主

### ヒースクリフ（茅場晶彦） 【原作1巻】
- モブではないが最終戦闘対象。75層攻略直後にラスボス化。**システム上の不死属性（イモータル・オブジェクト化）を自ら解除**して決闘に応じた点はSAWのGM戦設計の参考になる

## 5. SAW実装用：SAO共通の敵・戦闘システム仕様

1. **カラーカーソル**：敵はカーソル色で識別（モンスター=赤系。格上ほど濃色）。ザ・ファタル・サイスのような「カーソル無し」は規格外の演出
2. **HPバー複数本制**：ボスは2〜5本。1本削るごとに行動パターン変化・武器チェンジ・取り巻き追加などのフェーズ移行
3. **ラストアタック（LA）ボーナス**：とどめを刺した個人に専用レアが入る。レイド内の功名争い・確執の火種として物語装置化できる
4. **取り巻きの補充湧き**：ボス戦中に雑魚が再湧きする（1層センチネル方式）
5. **結晶無効化空間**：74層以降のボス部屋等では転移・回復結晶が封印される「アンチクリスタル・エリア」。撤退不能＝全滅リスクの根源
6. **罠（トラップ）**：宝箱型アラーム→モンスターハウス＋転移封印のコンボ（黒猫団壊滅パターン）
7. **β版と正式版の差分**：βテスター知識が裏切られる（イルファングの武器変更、2層の追加ボス等）。「攻略本が当てにならない瞬間」を意図的に作る設計
8. **クエスト連動ドロップ**：レア個体限定ドロップ（ネペントの卵珠）、討伐でなく巣の採取（クリスタライト）、期間限定ボスの一点物（蘇生アイテム）など入手経路の多様化
9. **環境ギミックボス**：水没ボス部屋（4層）、部屋自体がボス（5層）、無敵＋パズル解除（6層）、恒久デバフを残すボス戦（7層）
10. **フィールド食材・生産系ドロップ**：S級食材ラグー・ラビットのように、戦闘外コンテンツ（料理・鍛冶）へ流れるドロップ設計
