## 設計メモ

- **熟練度帯の骨格**:基本単発(0〜100)→2連(100〜250)→機能単発(220〜400)→3〜4連(400〜500)→重単発(550)→多連撃(700〜)→奥義級(950)。参考資料の進行モデルに準拠
- **500の境界**:プント・フィナーレ以降は名前がイタリア語に変わる。到達者が少なく、城が分類せず考案者の原記録のまま保存しているため(世界観演出。スキル一覧UIで言語が切り替わる違和感自体が伏線)
- **既存システムとの連動**:インペトゥス=距離システムの接近を攻撃と同時化/プルサーレ=ノックバックでバックステップ戦術を補完/クアドルム=部位破壊ビルド向け/属性(斬・刺・打)を意図的に散らし、部位弱点システムと噛ませる
- **熟練度カーブとの整合**:growth_scale=50000の漸近曲線上、950到達は超長期プレイ域。チェント・ラーメが「到達記録なし」の神話級であることと整合。カプストーン(1000)の直前報酬として機能
- **反動ロックアウトとの整合**:多連撃・高倍率技はCT長めで設計。プント・フィナーレのみロックアウト延長のデメリット持ち(要実装可否判断)
- **補助式との整合**:片手直剣熟練度50ごとに得る補助式ptで、永続ボーナスを選択取得する。錬技の候補解放とは別軸で、候補は最初から全開示する。詳細は `docs/spec/design/one_handed_sword_skill_mods.md`。
