# 片手直剣補助式 設計

片手直剣熟練度により得る恒久ボーナス群。外部作品由来の名称は使わず、ゲーム内では「補助式」と呼ぶ。

## 基本仕様

- 補助式の候補は最初から全開示する。
- 熟練度による候補解放は行わない。
- 片手直剣熟練度50ごとに補助式ptを1得る。熟練度1000で最大20pt。
- 補助式は習得後に永続し、自由な付け替えはできない。
- 補助式ptはステータス振り分けと同じく振り直し不可のため、習得前に「はい/いいえ」の確認を必ず挟む。
- 同じ補助式を複数回習得できるものがあり、段階が上がるほど次段階の必要ptも増える。
- 錬技発動後の反動ロックアウトは補助式で短縮しない。

保存先は `skills.learn_condition_data` の `skill_mods` キー。DBスキーマ変更を避け、既存セーブ互換を保つ。

## UI

- 補助式候補は量が多いため、スキル詳細内では2列の名称一覧として表示する。
- 補助式ptは「補助式」見出しの右端に表示する。
- 名称をクリックすると、画面位置を補助式一覧の先頭へ移動し、固定ヘッダーに先頭行が隠れない状態で、その下に分類・現在段階・効果・次段階必要pt・習得確認ボタンを詳細表示する。
- 習得可能な補助式でも即時習得は行わず、確認状態で「はい」を押した場合のみ補助式ptを消費する。「いいえ」は詳細表示へ戻る。

## 個別錬技Lv効果

個別錬技Lvは使い込みで上昇し、片手直剣補助式とは別軸でその錬技だけを強化する。

- 威力: `floor(Lv / 5)%` 加算。Lv100で+20%。
- 命中: `floor(Lv / 20) * 2` 加算。Lv100で+10。
- 耐久: `floor(Lv / 30)` だけ錬技耐久消費を軽減。最低消費1。
- CTと反動ロックアウトは個別錬技Lvでは短縮しない。
