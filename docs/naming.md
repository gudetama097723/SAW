# 用語・名称対応表(naming.md)

このファイルはプロジェクト全体の**用語の正**である。
コード・CSV・UIテキスト・ドキュメントのすべてで、この表の「新名称」を使用する。
旧名称(SAO由来)は今後一切使用しない。

- ✅ 確定 / 🔶 仮称(響き要検討) / ❌ 未定(要決定)
