## 1. 舞台:城ヴァールハイム

### 1.1 名前の由来(終盤開示用ギミック)
- 独語 **Wahl(選別・選択)+ Heim(家郷)=「選別の家」**
- 序盤:ただの古い地名として提示する
- 終盤反転①:「ここは最初から選別場だった」
- 終盤反転②:Wahlは「自ら選ぶ」の意でもある ──「城が選ぶのではない。お前が選ぶのだ」

### 1.2 構造:選別の漏斗(ろうと)
- 全100層。**上るほど層が狭くなる円錐(漏斗)状**。各層の広さ=城が想定した到達人数。100層はたった一人分の広さしかない(想定)
- 1層が最も広く、集落が最も多い(最低5つ)。上層ほど集落が減り、フィールドが長くなる
- **集落と住人の数=歴代挑戦者の到達記録そのもの**。補給所(店・宿)は挑戦者がいた場所にしか作られていない。層の風景自体が統計になっている
- 住人は失格した層に住まわせられる → 上層の住人ほど精悍で、直伝スキルが強い(縦方向の人物設計指針)
- 各層は独立した閉鎖世界(町・自然・遺跡等)
- 層間は**登攀路(とうはんろ)**で接続される(§7参照)
- 10層ごとに城の「時代/文化圏」が変わる(層テーマ設計は今後策定)
- 90層以上は到達記録が存在しない=**住人すらいない未踏領域**(漏斗構造の帰結)
- 50層に「一度きりの不可逆な選択」を配置予定(中盤の山場)
- 難易度設計の柱:敵の強さだけでなく「**安全地帯の希薄化**」で難化させる。上層ほど回復・補給・クエストの機会が減り、1層で学んだ試験要項の習熟度がそのまま生存率になる

### 1.3 命名規則(推奨)
- 地名・町名:ドイツ語系(〜ドルフ、〜ブルク 等)
- スキル体系:ラテン語系
- ※武器・モンスター名の規則は今後策定

## 2. 世界の二層構造(表の顔と真相)

本作の物語は「表向きの世界」と「真相」の二層で構成される。
真相は階層踏破に応じて断片的に開示される(解明型の推進力)。

| 要素 | 表向き | 真相 |
|---|---|---|
| 各層の暮らし | 満ち足りた楽園。誰も上を目指す理由がない | 住人は全員、記憶を消された**元・挑戦者**。「満足」は城が与えた鎮静 |
| 塔 | 開かずの古い建物。風景の一部 | 選別試験の本線。住人には登る動機ごと消されている |
| モンスター | 昔からいる外の脅威。天災に近い自然現象 | 城の**免疫系**。素材は住人から回収した記憶。本来の標的は「登る者」 |
| 衛士団(自警組織) | 町を守る狩人たち。定期的な間引き | 実態は形骸化した儀礼。免疫系は住人を標的にしないため脅威は小さい |
| 道具屋・鍛冶屋 | ごく普通の生業 | かつて挑戦者のために城が用意した**補給所の残骸**。店主は理由を忘れて店を続けている |
| 妙に戦い慣れた住人 | 「生まれつき筋がいい」 | 上層まで登った元・挑戦者。記憶は消えたが身体の癖が残っている |

### 演出メモ
- プレイヤーが層に滞在すると免疫系が活性化し、モンスターが凶暴化する。住人は「近年まれにみる大発生」と困惑し、主人公はうっすら疑われる(異物としての孤独の演出)
- 誰も買わない業物を打ち続ける鍛冶屋が、主人公という「本来の客」を迎えて理由もわからず涙する ── 等、補給所設定は情感の source として活用する

## 3. 城の目的:選別装置

- 城はヴァールハイム全体で一つの**試験装置**であり、100層を踏破できる「たった一人」を探している
- 歓迎(補給所)と拒絶(免疫系)の矛盾は、両方が「試験」の一部であることで解消される
- 失格者を殺さず、記憶を消して住人化するのは城なりの慈悲(=不合格者の保管)
- ソロ制の理由:試験だから。合格者は一人でいい
- 城の人格イメージ:**公正で、几帳面で、慈悲があり、しかし絶対に合格点を下げない試験官**。挑戦者を憎んでいない。むしろ愛している

### 城が探している「たった一人」の正体
腕力の強者ではなく ── **何度消しても、消えない者**。
楽園を与えても満たされず、記憶を奪っても欠落に気づき、失格させても再び扉を叩く、「書き換え不能な自己」を持つ存在。

### 二種類の敗者(住人の構成)
各層の住人=元・挑戦者は二種に分かれる。
1. **塔に挑んで敗れた者(多数派)**:登攀路の桁違いの免疫系に資格を削り切られ、失格・住人化した者。第一層に集落が多い最大の理由
2. **塔に挑まなかった者(静かな多数派)**:塔の恐ろしさを知り、あるいは楽園の快適さに沈み、剣を抜かずに定住した者
- ①は「塔の中の技」を持つ(直伝スキルの出所)。②は持たない ── 住人の造形の差別化軸
- フィールドの敵が弱いのは「計測モード」であると同時に、**油断を作る罠**でもある。城は嘘をつかないが、本試験(登攀路)との落差を警告しない。公正だが、親切ではない

## 4. ゲームシステム=試験要項(世界観内説明)

すべてのゲームシステムは「城の計測・評価機能」として世界観内で説明される。

| ゲームシステム | 世界観上の正体 |
|---|---|
| レベル | 城による評価。挑戦者の存在をわずかに「強く書き換える」承認行為 |
| 経験値 | 評価の蓄積 |
| HP | 肉体の耐久値ではなく「**挑戦者資格の残量**」 |
| ダメージ | 免疫系による資格の摩耗 |
| ゲームオーバー(HP0) | 死ではなく**失格** → 記憶消去 → 住人化 |
| リトライ/周回 | 失格しても「また気づいて、また登り始める」主人公の異常な執念(§5参照) |
| ステータス振り分け(筋力/俊敏) | 「どう越えるか」の城への**申告**。筋力=力で越える、俊敏=速さで躱す |
| (拡張案)ビルド別の敵挙動 | 城は申告に応じて試練を調整する。実装コストと相談 |
| スキル獲得 | **歴代挑戦者の解答アーカイブ**の開示(詳細は§4.2「錬技と直伝」参照) |
| 回復薬・宿屋 | 資格の補填。補給所機能の一部 |
| 道具屋・鍛冶屋 | 試験運営側の補給拠点の名残 |
| モンスター | 試験官(免疫系)。素材は回収された記憶の残骸 |
| プレイヤー名入力 | **仮名の申告**。真名は失われている/城に預けられているため、試験中は自ら名乗った仮の名で記録される |
| パスワード | **誓句(せいく)**──城にすら読めない、書き換え不能な自己の最初の一片。城は照合結果しか知り得ない |
| ログイン | 資格照合。誓句により「前回までの自分の続き」であることを証明する |
| ログアウト | 試験の中断。城は中断を認めている(公正な試験官のため) |
| セーブデータ | 城の試験記録簿 |
| 料理バフ | 住人の**消え残った記憶**が宿る一皿。食すと存在の輪郭が一時的に濃くなる |
| 薬・強化剤バフ | 城公認の「**一時的な追記**」。持ち込み可の試験としての規定内補助 |
| NPCクエスト | 住人の消された記憶の、**消え残った未練の代行**。住人は理由の分からない衝動として抱えている |
| クエスト経験値 | 「どう登るか」への採点。未練解消=モンスター素材の削減=世界の傷を塞ぐ行為への評価 |
| お金(刻銭) | 城が鋳造した「**譲渡できる評価**」。経験値(譲渡できない評価)の物質形態。補給所決済用に発行された |
| クエスト報酬の武器 | 依頼主自身の挑戦者時代の得物。**遺品の継承**(スキルアーカイブの物質版) |
| インベントリ | **携行録(けいこうろく)**。物品を記録化して城に預ける試験支給品。持ち物はすべて城に把握されている |
| アイテムの出し入れ | 記録化/実体化。「携行録の頁をめくる」 |
| 所持重量 | **追記許容量**。城が一人の挑戦者に認める記録の上限。重い物ほど記録が濃い |
| 筋力→所持重量増 | 「多くを背負って越える」という型の申告への、城の応答 |
| 重量オーバー | 規定超過。城が追記を拒否している状態 |

### 4.1 バフの二系統
- **料理(人の記憶由来)**:住人の身体が覚えている味。記憶は消えても手が覚えている。高級料理ほど濃い記憶=強いバフ
  - 演出例:「なぜか、懐かしい味がした」/店主「この料理、誰に習ったんだったか」
- **薬・強化剤(城の規定由来)**:補給所支給品の系譜。バフ時間切れ=「追記の有効期限」
- この出所の違いは§4.3「内側の力と外側の力」の対立軸に接続する

### 4.2 スキル獲得の二系統:錬技と直伝
- **錬技(れんぎ)── 使い込みによる獲得(城経由)**
  - 同カテゴリの武器を使い続けると獲得。世界観上は:城が挑戦者の一挙一動を観測しており、型が先人の解答に到達したと認定した瞬間、アーカイブが開示される
  - 武器カテゴリ縛りの理由:アーカイブは武器種ごとに分類された試験記録だから
  - 熟練度ゲージ=「城の観測進度」。習得演出:「ふいに、手が勝手に動いた。知らないはずの型で」
  - 基本的な戦闘スキルはこの系統で網羅し、ビルドの自由度を担保する
- **直伝(じきでん)── クエスト報酬による獲得(城を経由しない)**
  - 未練の代行を果たした住人から、身体が覚えていた技が直接託される。本人は自分がその技の使い手だったことを知らない
  - 演出例:「なぜだろうね、あんたにこれを教えなきゃいけない気がするんだ」
  - 直伝スキルは**アーカイブに載っていない技**=城の帳簿の外にある力。数を絞り一点もの扱いにする
  - 差別化案:直伝スキルの説明文のみ一人称にする(「わしはこの突きで三十層を抜けた──気がする」)
- スキル説明文には「考案者の痕跡」を一行入れる(例:「──この技の記録者は、45層で失格した」)

### 4.3 対立軸:城の内側の力と外側の力
システム群は二つの出所に分類され、この軸は最終局面の設計に使用する。
- **城の内側(観測・記録されている力)**:錬技、薬・強化剤、刻銭、携行録、レベル・評価
- **城の外側(城の帳簿にない力)**:誓句(パスワード)、直伝、料理(人の記憶)、「城に預けていない何か」
- 終盤、「城の想定外の一手」が必要になる局面では、外側の力だけがその資格を持つ(伏線としてシステムの獲得経路自体が機能する)

### スキル設計の指針
- スキル説明文に「考案者の痕跡」を一行入れる(例:「──この技の記録者は、45層で失格した」)。フレーバーテキスト全体を墓碑銘として機能させる
- ソロゲームでありながら「技の一つ一つが先人の遺産」= **一人で戦っていない**構造を作る(絆の物語の、オリジナルな裏返し)
- 中盤最大の仕掛け:スキル記録の中に**主人公自身の前回の挑戦の痕跡**を発見する。見覚えのない技に、なぜか手が馴染む

## 5. 主人公

- 名前:ゲーム中は「挑戦者」等の仮称で呼ばれる(真名はクリア報酬 §6)
- 動機:自分の中に「**消された欠落**」があることに気づいている。何を失ったかは思い出せないが、欠けている感覚だけがある。欠けたままの自分では、楽園の満足すら本物か分からない ── だから登る
- 正体:**再挑戦者**。かつて一度登り、どこかの層で失格して住人化されたが、鎮静が効ききらなかった個体
- 周回プレイの説明:何度失格しても「また気づいて、また登り始める」── リトライというメタ行為を主人公の執念として物語に回収する

## 6. 頂上の報酬とエンディング

### 6.1 物語的報酬(C幹)
**「一人分の本物」= 完全な自己。**
この世界では、レベルもHPもスキルも城による書き換えと貸与であり、「城に一切触られていない自分」がどこにもない。頂上で合格者に返されるのは、記憶も力も選択もすべてが自分のものである状態。
→ 動機(欠落の回復)と報酬(完全な自己)が完全に一致する。

### 6.2 最終選択(分岐エンディング)
完全な自己を取り戻した主人公に、城が最後の問いを投げる。
「取り戻した記憶の中身が、もし望まぬものだったら? ── それでも自分を選ぶか」

| 分岐 | 内容 |
|---|---|
| A:外へ出る | 完全な自己を取り戻した者だけが「外」を認識できる。城の外への唯一の扉 |
| B:継ぐ | 城の管理者の座を継承し、次の挑戦者を待つ側になる |
| C:終わらせる | 城を停止させ、住人(元・挑戦者)を解放する。楽園も消える |

分岐によってエピローグの住人たちの結末が変化する。

### 6.3 プレイヤーへの明確なご褒美(3レイヤー)

**レイヤー1:システム的報酬(手に残るもの)**
- **真名の解放**:クリアで主人公の本当の名前が判明。以後その名でプレイ可能+ステータス上限解放
  - ゲーム開始時に入力した名前=仮名(§4参照)の意味がここで反転する。「お前があの日名乗った名は、仮初めだった」
- (アップデート弾候補)**継承者モード**:B分岐回収。2周目を「管理者」として開始し、敵配置・ドロップ率等の「管理者権限」を数個操作できる
- (アップデート弾候補)**101層**:城が想定していなかった「試験の外」の隠し層

**レイヤー2:記録的報酬(誇れるもの)**
- **クリア証明書(合格証)の発行**:名前・ビルド・失格回数・継承スキルの系譜を刻んだ一枚絵を生成、SNS共有可能に
- 失格回数が多いほど称号が良くなる(「不屈の」「消えざる」等)── 死んだ人ほど自慢したくなる逆転設計。拡散装置として集客にも寄与

**レイヤー3:物語的報酬(心に残るもの)**
- スキル考案者たち(=各層の住人)の「その後」がエピローグで描かれる
- 1層で最初に会う住人(道具屋の店主等)が、エピローグで初めて主人公を**真名で呼ぶ**

初期実装の推奨セット:**真名の解放+クリア証明書+最初のNPCの一言**(コスト低・効果大の順)

## 7. 登攀路と関の町(層間構造)

### 7.1 登攀路(とうはんろ)── 層間ダンジョン
- 各層と次層をつなぐ塔内迷宮。**フィールドとは敵の強さが桁違い**
- 世界観上の定義:フィールド=試験要項の説明と計測の場(観測用免疫系)、登攀路=**本採点の場**(選別用免疫系)。城が本気で拒む場所
- 構造:複数階のダンジョン型。最深部に**層主(フロアボス)=各層の主任試験官**、その先に次層への扉
- 層主撃破=その層の「合格判定」

### 7.2 関の町 ── 登攀路手前の攻略拠点跡
- 各層の登攀路手前に存在する、**かつての攻略前線基地**だった町
- かつて挑戦者たちが集い、装備を整え、情報を交わした拠点。挑戦者が絶えた今、そこに住むのは**その塔に敗れた者たち**。自分たちがなぜ塔の目の前に住んでいるのか誰も覚えていない
- 名残の演出:使われない大量の宿部屋、武具屋の異常な在庫、壁の意味不明な攻略メモ(=真相開示の断片テキスト)
- **塔に最も近い町なのに、住人は誰も塔の話をしない**(不気味さの演出。ボス前の空気作り)
- 直伝スキルの質が高い(住人は塔まで到達した実力者揃い)
- ゲーム機能:ボス前の最終補給・回復拠点
- 上層に行くほど関の町は小さく廃墟に近づき、最後は「誰かの野営の跡」だけになる(漏斗構造の視覚化)

## 8. 第一層設計

### 8.1 チュートリアル層の二重の意味
- **表向き**:城は公正な試験官なので、採点前に試験要項を説明する。第一層=「採点前の説明会場」
  - 敵がどこでも同程度に弱い=免疫系が「計測モード」(そして油断を作る罠)
  - レベルが上がりにくい=説明期間中、城はほとんど採点しない
  - **仕様(携行録・料理・錬技・誓句)を学ぶことが第一層の実力**=ゲームデザイン意図の世界観翻訳
- **真相**:最初の選別はすでに始まっている。第一層の合否は「2層への扉をくぐるかどうか」自体で決まる
- 2層への登攀路の入口に城からの一文:「**要項の説明は以上である。健闘を祈る**」(チュートリアル終了宣言)

### 8.2 第一層の集落(5つ)

### 8.3 第一層のフィールド
- **ゆりかごの野**(旧:はじまりの草原):ヴィーゲンブルク⇔ヒルテンドルフ。既存5エリア構成
  - エリア別の学習割当:近郊=移動・会話・携行録/整備された街道=店・刻銭・薬バフ/**風見の原**(旧:草原中央)=戦闘基礎・錬技の入口/獣道・狼の縄張り=危険・失格・料理バフの実用(第一層唯一の危険地帯、主=事実上の卒業試験)/ヒルテンドルフ牧野(旧:ホルンカ村近辺)=クエスト・直伝の入口
- **骨石の岩場**:エルツドルフ周辺。採取・素材ドロップ特化
  - 鉱石=**記録の沈殿**(城の書き換えの力が物質に沈殿したもの。だから追記に耐える武器の器になる)
  - 岩場の免疫系は沈殿した記録を核に生成される → 砕くと素材が残る(高ドロップ率の世界観的必然)
- 他、森・湖水系フィールド、関の町へ至る街道フィールドで計4〜5本を想定
- 小規模ダンジョン(廃坑・遺跡・狼の巣穴など)を数個:「かつての挑戦者の攻略拠点跡」「記録の沈殿が濃い場所」。宝箱=誰かの遺した携行録の残骸
- 登攀路(1層)の位置:どの集落の生活圏にもない場所(住人が視界に入れない場所にある、という香りづけ)

### 8.4 エルツドルフと武器生産の世界観
- 鍛冶村=補給所の残骸の中でも**武器補給の中枢**だった場所。村人は理由を忘れたまま「誰も買わない武器」を打ち続けてきた
- プレイヤーの武器生産=素材(記録の沈殿:内側)+住人の手が覚えた鍛冶(外側)の**合作**。生産武器に「城の帳簿に載っていない武器」という物語的意味を持たせる余地あり

## 9. 既存実装との対応(実装を変えずに世界観で説明する箇所)

- **敗北処理(現行:拠点送還+アイテム半数ロスト+col全ロスト)**:世界観上は「HP0=失格=住人化」だが、主人公は「消えない者」なので城は住人化に**失敗**し、やむなく資格を再発行して拠点に戻す。col全ロスト=譲渡可能な評価の没収、アイテム半減=携行録の記録の摩耗。**コード変更不要**。失格を繰り返すほど主人公の異常性の反復描写になる
- **熟練度到達でスキル自動習得**:「城の観測完了によるアーカイブ開示」そのもの
- **レストランの食材消費バフ**:「記憶の味」に直結
- **親密度上昇で自動発動するトリガー式クエスト**:「未練の代行」の実装として整合(受注せず勝手に完了する不思議さに世界観上の必然が付く)
- **用語の置換(col→刻銭、ソードスキル→錬技 等)は docs/naming.md を正とする**

## 11. 権利面の設計方針(重要)

- 影響元(SAO等)の**固有名詞・キャラクター・具体的展開は一切使用しない**
- 「浮遊城の階層攻略」「デスゲーム」「システム補助つき必殺技」等の**アイデア・構造レベルの要素のみ**を使用する
- キャラクターは「名前+設定+関係性」のセットで完全に別物として設計する
- 影響を受けたことの公言は自由(「SAOに影響を受けて作った」はOK)
- タイトル・城名に既存商標と類似する語(Sword Art等)は使用しない
- 本方針により、広告・課金による収益化、就職活動でのポートフォリオ利用が可能
